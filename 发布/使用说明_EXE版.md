# 随机抽人（桌面版）使用说明

一个用于课堂点名、谈心谈话排人的小工具：每次随机抽一名学生，抽中后自动从抽取池移出，
下次不会再抽到同一个人。约 200 人规模，不联网、不上传任何数据。

本文只针对**桌面版（随机抽人.exe）**。

---

## 一、第一次打开

把 `随机抽人.exe` 放到一个**固定文件夹**里（例如桌面新建一个「抽人」文件夹），双击打开。
首次启动需要解压，**请等 2~4 秒**，窗口就会出来。

### 可能会看到蓝色提示框

因为程序没有购买数字签名，Windows 第一次运行会弹出
**「Windows 已保护你的电脑」**。这不是病毒提示，是所有未签名程序的通用提示。

处理方法：点左侧的 **「更多信息」**，再点 **「仍要运行」**。之后不会再提示。

> **可以直接把下面这段话发给接收方：**
>
> 这个程序没有购买数字签名，Windows 首次运行会提示「已保护你的电脑」，
> 点「更多信息」→「仍要运行」即可，是正常现象。
> 程序不联网、不收集任何数据，所有记录只存在本机。

### 运行环境

Windows 电脑即可，无需安装 Python 或其他软件。
界面用的是 Edge 浏览器组件（Windows 10/11 自带）。

---

## 二、先准备数据

程序本身不含学生数据，第一次用需要导入。有两样东西：**名单**和**课表**。

### 1. 导入名单

点顶部「**名单管理**」→ 左上角「**导入名单（Excel / CSV）**」。

支持的格式：

| 格式 | 说明 |
|---|---|
| `.xlsx` | Excel 新格式 |
| `.xls` | Excel 旧格式（教务系统导出的通常是这种） |
| `.csv` | 文本表格 |

表格里需要有 **姓名** 这一列，学号和班级可选。列名写「姓名/学号/班级」会被自动识别，
**列的先后顺序无所谓**。例如：

```
姓名,学号,班级
张三,2024240101,计算机2401
李四,2024240102,计算机2401
```

几个细节：
- 表格**首行是标题**（如「计算机2401班学生名单」）也没关系，会自动跳过
- 只有姓名、没有学号班级也能导
- **可以一次选多个文件**（按住 Ctrl 多选）。例如一个班一个文件，一次全选导进来
- 完全重复的条目会自动跳过；**同名不同学号会全部保留**并提示你核对

### 2. 导入课表

点顶部「**课表**」→「**导入课表（Excel / CSV）**」。

教务系统导出的课表文件**可以直接导入**，两种常见格式都认：
- 「学生个人课表_学号.xls」
- 「课表打印-班级名.xls」

也可以一次选多个文件。导入后会提示写到了哪个班：

> 已导入 22 个课时，写到 **班级 242013**

**如果提示「课表里的班级在名单里不存在」**，说明课表里的班级名和名单里的对不上。
程序会列出名单里现有的班级名，请把两边改成一致后重新导入
（不报错直接导入的话，课表不会生效，还看不出来）。

### 3. 填「第 1 周从哪天开始」

在「课表」页的**设置**卡片里，填写**第 1 周的周一日期**，然后点「保存设置」。

这一项很重要：不同周的课不一样，程序需要靠它算出"现在是第几周"。
同一张卡片里还能设「离下节课不足多少分钟不算空闲」，默认 30 分钟。

**没填这一项的话**，用了周次的课表会按"每周都有课"保守处理——
会少抽一部分人，界面会明确提示这一点。

## 三、日常使用

### 抽取

回到「抽取」页，点「**开 始 抽 取**」，或者直接按 **空格 / 回车**。
名字会快速滚动约 1 秒后定格，**抽中的人立即从抽取池移出**，本轮不会再被抽到。

### 顶栏四个数字

| 数字 | 含义 |
|---|---|
| **此刻可抽** | 现在能抽的人（已经排除正在上课、马上要上课、已谈过的） |
| **未谈** | 本学期还没抽到过的人数（与时间无关） |
| **总人数** | 名单里的总人数 |
| **当前学期** | 第几个学期 |

「此刻可抽」会随着上下课变化，界面上方还会显示现在周几、第几周、当前是哪节大课。

### 抽到的人来不了怎么办

点抽取历史里那条记录右侧的「**撤回**」——该学生会回到抽取池，可以重新抽。
撤回后序号会自动重排，不会留下空缺。

> 注意：撤回等于**撤销这条谈话记录**。如果真的谈过了，就不要撤回。

### 一轮抽完之后

所有人都谈过了之后「此刻可抽」会变成 0，点「**开始新学期**」即可：
所有人回到抽取池，本学期的记录归档保留（历史里还能查到），学期序号 +1。

### 课表怎么影响抽取

程序会**自动排除此刻有课的同学**：

- 正在上课的 → 排除（大课内部那 10 分钟课间也算在上课）
- 距离下一节课开始不到 30 分钟的 → 排除（来不及过来）
  → **所以 20 分钟的大课间，如果后面还有课，同样算不可用**
- 下一节课还很远、或者今天课已经上完了 → 算空闲

但有两种情况不会排除任何人：
- **还没录课表**（此时和没有课表功能时一样，谁都能抽）
- 课表里用了周次但没填「第 1 周从哪天开始」

一个人都抽不出来时，界面会写明原因，例如：

> **此刻可抽 0 人**
> 未谈的 5 人此刻都不可抽：3 人正在上课，2 人马上要上课。
> 下一段空闲大约 11:40 之后。

如果确有急事非要现在抽，勾选下方的「**忽略课表，强制抽取**」即可。

## 四、名单管理

点顶部「**名单管理**」：

- **直接点表格里的姓名/学号/班级即可修改**，点别处自动保存
- **停用**：暂时不参与抽取（请假、转走）。注意停用的人**重置学期也不会回到池子**
- **删除**：从名单彻底移除（已有的抽取记录仍保留姓名，不会变成空白）
- **勾选后批量操作**：每行最左侧有勾选框，表头可全选（**只作用于当前搜索出的行**）。
  勾选后出现操作条，可一次停用 / 启用 / 删除多人，不必一个个点
- 右上角有「导出备份」「导入备份」「清空名单」

---

## 五、数据在哪、怎么备份

**数据存在 exe 同目录的 `data.db` 文件里**，不在 exe 内部。

- **备份 / 换电脑**：把 `data.db` 和 exe 一起拷走即可，或者用「导出备份」存成一个文件
- **发程序给别人**：只发 exe 的话，对方打开是**空的**（没有任何学生数据）。
  要连数据一起给，就把 `data.db` 一起发过去（或者用「导出备份」让对方导入）
- 如果 exe 所在文件夹不可写（例如放在 `Program Files`），程序会自动把数据存到
  `%APPDATA%\随机抽人\` 里，不会报错

**建议**：每次谈完一轮后，用「导出备份」存一份留档。

## 六、常见问题

**双击后没反应？**
首次启动要解压，等 2~4 秒。如果还没出现，看一下任务栏是否已经打开（可能最小化了）。
也可以直接双击 `data.db` 所在的文件夹确认文件在不在。

**提示「无法连接后端」？**
点一下「开始抽取」重试；仍不行就关掉程序重新打开。

**一个人都抽不出来？**
看界面上的说明——它会写清是"都谈过了"还是"都正在上课"。
如果显示的是"都正在上课"，说明课表在正常工作，换个时间再抽即可。

**换了新课表，导入后旧课表还在？**
导入是**合并**而不是覆盖。换课表前请先点「**清空课表**」，再导入新的，
否则旧课表里有的时段会残留下来，和新课表混在一起。

**课表导入后提示班级不存在？**
课表文件里的班级名（如 `242013`）必须和名单里的班级名**完全一致**才能生效。
程序会列出名单里现有的班级名，改一致后重新导入。

**想一次性给全班禁用一个时段的人？**
在「课表」页勾选「编辑周次」后点方格可以填周次（如 `1-8`、`10-16`、`单`、`双`），
留空表示每周都有课。也可以直接点方格切换"这个时段有没有课"。

## 七、快速上手清单

1. 把 exe 放进一个固定文件夹，双击打开（首次遇到蓝框点「更多信息」→「仍要运行」）
2. 「名单管理」→ 导入名单（可一次选多个文件）
3. 「课表」→ 导入课表（教务的 `.xls` 直接导，可多选）
4. 「课表」→ 设置卡片里填「第 1 周从哪天开始」→ 保存设置
5. 回到「抽取」→ 点「开始抽取」或按空格
6. 抽到来不了的人 → 点该条记录的「撤回」
7. 一轮抽完 → 「开始新学期」
